# GymWeb: Gymnastics Federation of Zagreb County (GSZZ)

A full-stack, responsive web application designed for managing and displaying the activities of the Gymnastics Federation. 

## Tech Stack
- **Frontend**: React 18, Vite, Tailwind CSS 4, `shadcn/ui`
- **Backend**: Express.js, tRPC
- **Database**: SQLite (`better-sqlite3`), Drizzle ORM

## Features
- **Dynamic Frontend**: Modern, responsive UI displaying news, upcoming events, affiliated clubs, and regional results.
- **Admin Panel (CMS)**: A secure backend dashboard (`/admin`) allowing administrators to manage all federation entities (CRUD operations).
- **Global Settings Management**: Admins can easily update hero titles, subtitles, and contact routing information directly from the dashboard without altering project code.
